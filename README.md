# PHEW-AND-DEFENSE

HOW TO PLAY:
CONTROL:
 RED ROCKET:
   W     = UP

   A     = UP

   S     = DOWN

   D     = DOWN

   SHIFT = FIRE BULLET

   E     = PLACE WALL
   
---------------------------------------------------------------------------
  BLUE ROCKET:
   UP KEY = UP

   LEFT KEY  = UP

   DOWN KEY  = DOWN

   RIGHT KEY = DOWN

   CTRL      = FIRE BULLET

   NUMPAD-0  = PLACE WALL
   
---------------------------------------------------------------------------
GAME RULES:
 1. PLAYERS:
  1. RED ROCKET 
  2. BLUE ROCKET

 2. to score. the player must hit the SHIP (the thing behind each player) 3 times.
 
 3. to defend your SHIP from getting hit. you can use WALLS and place it behind your ROCKET
    so the other player cant hit your SHIP.

 4. when a WALL gets hit 2 times. it breaks.

 5. when a player's ROCKET gets hit 2 times. it gets destroyed and respawns after 2 second or few.

 6. when a player scores by hitting the SHIP 3 times. they gain 2 more WALLs.

 7. when a player shoots a BULLET. the player cant shoot another BULLET till it 
    hits something (example: SHIP, ROCKET, WALL)
    
---------------------------------------------------------------------------

HOW TO DOWNLOAD IT:
 1. install java 25 or newer.
 2. extract the zip file. 
 3. double click "PHEW AND DEFENSE.jar"


NOTE: if double-clicking the jar doesnt work.
      open "Command Prompt".
      run: java -jar "PHEW AND DEFENSE.jar"
      (if you have the jar in somewhere like Desktop.
       then first do cd Desktop then run that)
